## Routing

Files matching `npm` are scored by `filegroups/archive`, `filetypes/npm`, `general`. The ensemble's decisions apply the saved routing policy, including every level at or below the requested level. Ranking metrics use the signed distance from that policy's decision boundary. See [`route_policies.md`](../../route_policies.md).
